## 玩法

- **表情**：微笑 / 大笑 / 眨眼
- **场景**：海洋 / 星夜 / 樱花（背景、雾效、泡泡颜色联动）
- **动作**：招手、自动转台、泡泡特效、一键回视角
- **📷 拍照保存**：把当前画面导出为 PNG
- 左侧有角色档案卡；底部显示当前服装介绍
- 拖拽旋转 · 滚轮缩放 · 右键平移

## 技术

- Three.js r160（CDN importmap），单文件 `index.html`，无构建步骤
- 全程序化建模：长发分节搭建、鲸鱼鳍耳、Canvas 纹理小鲸鱼印花
- 关节化手臂（招手）、长发/尾巴摆动、呼吸浮动
