# 🐋 肥鱼 · 鲸鱼娘女仆 3D 换装

DeepSeek 社区二创形象「大肥鱼 / 蓝色大肥鱼」的程序化 3D 网页：蓝色鲸鱼娘女仆，支持一键换装。

在线体验（GitHub Pages）：https://WANGZIYEYE.github.io/feiyu-maid-3d/

## 玩法

- **换装**：🎀 经典女仆装 / 🌊 鲸鱼娘装 / 🍚 休闲居家装，一键切换
- **招手**：点「招手」按钮，肥鱼会抬手打招呼
- **旋转 / 泡泡 / 视角**：自动转台开关、上升泡泡特效、一键回到默认机位
- 拖拽旋转 · 滚轮缩放 · 右键平移

## 技术

- Three.js r160（CDN importmap），单文件 `index.html`，无构建步骤
- 角色全部由程序化几何体搭建（球体 / 胶囊 / 车削裙摆 / 双马尾），无外部模型文件
- 肢体关节化：肩部关节组实现招手动画；双马尾、鲸鱼尾随时间摆动
